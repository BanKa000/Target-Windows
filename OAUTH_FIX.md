Ошибка `invalid_client - client_secret is undefined` больше не возникает!

## Новый метод авторизации

Программа теперь использует **OAuth Implicit Flow через браузер** - это стандартный и самый надёжный способ авторизации ВКонтакте.

### Как это работает:

1. **Вы выбираете "1. Войти через браузер"**
2. **Программа автоматически открывает браузер** с страницей авторизации VK
3. **Вы авторизуетесь** любым способом:
   - Логин/пароль
   - QR-код
   - Через мобильное приложение
   - И т.д.
4. **После успешной авторизации** VK перенаправляет на локальный сервер программы
5. **Токен автоматически извлекается** из URL и сохраняется
6. **Готово!** Можно использовать программу

### Преимущества:

✅ **Работает с двухфакторной аутентификацией** - просто пройдите стандартную процедуру 2FA в браузере  
✅ **Не требует client_secret** - используется стандартный OAuth механизм  
✅ **Безопаснее** - пароль не передаётся через программу  
✅ **Надёжнее** - стандартный механизм VK, который всегда работает  
✅ **Поддерживает все способы входа** - QR-код, логин/пароль, и т.д.

## Как использовать

```bash
# Запустите программу
run_go.bat
```

1. Выберите **"1. Войти через браузер"**
2. Дождитесь открытия браузера
3. Авторизуйтесь в VK
4. После успешной авторизации закройте вкладку браузера
5. Используйте программу!

## Если браузер не открывается

Если браузер не открылся автоматически:

1. Скопируйте URL из консоли
2. Откройте его вручную в любом браузере
3. Авторизуйтесь
4. Токен будет автоматически передан в программу

## Альтернативный способ

Если возникли проблемы с браузером:

1. Выберите **"2. Использовать существующий токен"**
2. Получите токен вручную (см. раздел "Получение токена вручную" в README.md)
3. Вставьте токен в программу

## Технические детали

- **Метод**: OAuth 2.0 Implicit Flow
- **Локальный сервер**: запускается на случайном порту (127.0.0.1)
- **Таймаут**: 5 минут на авторизацию
- **App ID**: 2274003 (VK для Android)
- **Redirect URI**: http://127.0.0.1:{port}/callback

## Обновления в коде

### Новые функции:

- `openBrowser(url string)` - открывает URL в системном браузере
- `getVKTokenViaBrowser(clientID int)` - выполняет OAuth Implicit Flow

### Удалённые функции:

- `getVKToken(login, password, clientID string)` - больше не нужна

### Новые импорты:

- `net` - для локального сервера
- `os/exec` - для открытия браузера
- `runtime` - для определения ОС

## Решение проблем

### Браузер не открывается

**Решение:**
- Скопируйте URL из консоли
- Откройте его вручную в браузере
- Авторизуйтесь

### Токен не передаётся

**Решение:**
- Убедитесь, что авторизация завершена
- Проверьте, что в браузере отображается страница "Авторизация успешна"
- Попробуйте использовать опцию "2" для ввода токена вручную

### Таймаут

**Решение:**
- У вас есть 5 минут на авторизацию
- Если не успели - запустите программу заново
- Используйте более быстрый способ авторизации (QR-код)
