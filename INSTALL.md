# Инструкция по сборке VK Community Finder

## 🎯 Что вам нужно

Перед началом убедитесь, что у вас установлено:

1. **Node.js 18 или выше** 
   - Скачать: https://nodejs.org/
   - Проверить версию: `node --version`

2. **Windows 10/11** (64-bit)

3. **Свободное место**: минимум 2 ГБ

## 🚀 Пошаговая сборка

### Шаг 1: Установка зависимостей

Откройте командную строку (cmd) или PowerShell в папке проекта:

```bash
npm install
```

Это установит все необходимые пакеты (React, Electron, TypeScript и др.)

**Время**: 2-5 минут  
**Размер**: ~500 МБ

### Шаг 2: Сборка веб-приложения

```bash
npm run build
```

Это создаст оптимизированную версию веб-приложения в папке `dist/`

**Время**: 10-30 секунд

### Шаг 3: Сборка .exe файла

```bash
npx electron-builder --win --x64
```

Или используйте автоматический скрипт:

```bash
build.bat
```

Это создаст установщик Windows в папке `release/`

**Время**: 3-10 минут  
**Размер готового файла**: ~150 МБ

### Шаг 4: Установка приложения

1. Откройте папку `release\`
2. Запустите `VK Community Finder-1.0.0-Setup.exe`
3. Следуйте инструкциям установщика
4. Выберите папку установки (по умолчанию: `C:\Program Files\VK Community Finder`)
5. Создайте ярлык на рабочем столе (опционально)

## 🎮 Запуск приложения

### После установки

- **Ярлык на рабочем столе**: двойной клик
- **Меню Пуск**: найдите "VK Community Finder"
- **Папка установки**: `VK Community Finder.exe`

### Без установки (портативный режим)

Если вы не хотите устанавливать, можете запустить напрямую:

```bash
run.bat
```

Это запустит приложение без создания установщика.

## 🔧 Режим разработки

Для разработки и тестирования:

```bash
dev.bat
```

Это запустит:
1. Vite dev-сервер на `http://localhost:3000`
2. Electron приложение с открытыми DevTools

## 📦 Альтернативные варианты сборки

### Портативная версия (без установки)

```bash
npx electron-builder --win portable
```

Создаст один `.exe` файл, который можно запускать без установки.

### 32-битная версия

```bash
npx electron-builder --win --ia32
```

Для старых компьютеров с 32-битной Windows.

### Все платформы сразу

```bash
npx electron-builder --win --mac --linux
```

## 🎨 Изменение иконки

1. Создайте иконку 256x256 или 512x512 пикселей
2. Конвертируйте в формат `.ico` (используйте онлайн-конвертер)
3. Сохраните как `build/icon.ico`
4. Пересоберите приложение

## ❓ Частые проблемы

### Ошибка: "npm install" не работает

**Решение**:
```bash
# Очистите кэш npm
npm cache clean --force

# Удалите node_modules и package-lock.json
rmdir /s /q node_modules
del package-lock.json

# Установите заново
npm install
```

### Ошибка: "electron-builder" не найден

**Решение**:
```bash
npm install electron-builder --save-dev
```

### Ошибка при сборке .exe

**Возможные причины**:
- Антивирус блокирует создание .exe
- Нет прав администратора
- Недостаточно места на диске

**Решение**:
- Добавьте папку проекта в исключения антивируса
- Запустите командную строку от имени администратора
- Освободите место на диске

### Белый экран в приложении

**Решение**:
1. Нажмите F5 для обновления
2. Проверьте консоль (F12) на ошибки
3. Пересоберите приложение: `build.bat`

### Приложение не запускается после установки

**Решение**:
1. Запустите от имени администратора
2. Проверьте совместимость (Properties → Compatibility)
3. Переустановите в другую папку

## 📊 Требования к системе

### Минимальные

- **ОС**: Windows 10 (64-bit)
- **Процессор**: Intel/AMD 64-bit
- **ОЗУ**: 2 ГБ
- **Место на диске**: 500 МБ
- **Интернет**: для работы с VK

### Рекомендуемые

- **ОС**: Windows 11 (64-bit)
- **Процессор**: Intel Core i3 / AMD Ryzen 3 или выше
- **ОЗУ**: 4 ГБ и более
- **Место на диске**: 1 ГБ
- **Интернет**: стабильное соединение

2. **Экспортируйте в Excel** - проверьте что файл создаётся
3. **Поделитесь установщиком** - раздайте `release\VK Community Finder-1.0.0-Setup.exe`

2. Проверьте консоль (F12) на ошибки
