# 🔧 Исправление ошибки "Flood control" (код 9)

## Что означает эта ошибка

**Flood control (код 9)** - VK временно заблокировал запросы из-за слишком частых попыток авторизации.

Это **временная блокировка**, которая обычно длится 15-30 минут.

## Решение

### Вариант 1: Подождите 15-30 минут (рекомендуется)

1. Закройте программу
2. Подождите 15-30 минут
3. Запустите программу снова:
   ```bash
   run_go.bat
   ```
4. Введите тот же токен

### Вариант 2: Получите новый токен

Если ожидание не помогло:

1. Откройте в браузере:
   ```
   https://oauth.vk.com/authorize?client_id=2685278&scope=offline,groups&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&v=5.199
   ```

2. Авторизуйтесь в VK

3. Скопируйте новый токен из URL (между `access_token=` и `&expires_in`)

4. Вставьте в программу

### Вариант 3: Проверьте, что токен правильный

Убедитесь, что:
- Токен начинается с `vk1.a.`
- Токен скопирован полностью (без пробелов)
- Не скопированы `access_token=` или `&expires_in`

## Почему возникла эта ошибка

Возможные причины:
- Слишком много попыток авторизации за короткое время
- Использование одного токена в нескольких программах
- Блокировка со стороны VK

## Что делать, если ошибка повторяется

1. **Не пытайтесь авторизоваться слишком часто**
   - Подождите минимум 5 минут между попытками

2. **Используйте один токен**
   - Не создавайте много токенов
   - Используйте один токен для всех попыток

3. **Проверьте свой аккаунт VK**
   - Убедитесь, что аккаунт не заблокирован
   - Проверьте, что можете войти в VK через браузер

   Или получите новый токен по инструкции в README.md
