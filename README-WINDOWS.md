# VK Community Finder - Десктопное приложение для Windows

Программа для поиска сообществ ВКонтакте через парсинг веб-страниц. Автоматически собирает контактную информацию и экспортирует данные в Excel.

## 🚀 Быстрый старт

### Способ 1: Запустить готовое приложение (если уже собрано)

1. Откройте папку `release`
2. Найдите файл `VK Community Finder-1.0.0-Setup.exe`
3. Запустите установщик
4. Следуйте инструкциям мастера установки
5. Запустите программу из меню Пуск или ярлыка на рабочем столе

### Способ 2: Собрать приложение самостоятельно

#### Требования

- **Windows 10/11** (64-bit)
- **Node.js** версии 18 или выше ([скачать](https://nodejs.org/))
- **Git** (опционально, для клонирования репозитория)

#### Шаги сборки

**1. Установите зависимости**

Откройте командную строку (cmd) или PowerShell в папке проекта:

```bash
npm install
```

**2. Соберите веб-приложение**

```bash
npm run build
```

**3. Соберите .exe файл**

```bash
npx electron-builder --win --x64
```

Или используйте автоматический скрипт:

```bash
build.bat
```

**4. Найдите готовый установщик**

После сборки установщик будет в папке `release\`:
- `VK Community Finder-1.0.0-Setup.exe` - установщик для Windows

## 📖 Инструкция по использованию

### 1. Запуск приложения

После установки запустите программу:
- Через ярлык на рабочем столе
- Через меню Пуск → VK Community Finder
- Или напрямую из папки установки

### 2. Поиск сообществ

1. В поле "Критерии поиска" введите ключевые слова (например: "автосервис", "доставка еды")
2. Нажмите кнопку "Найти" или клавишу Enter
3. Программа найдёт сообщества и автоматически соберёт их контакты

**Расширенные настройки:**
- **Тип сообщества**: Группа / Публичная страница / Встреча
- **Сортировка**: По релевантности / По скорости роста
- **Макс. результатов**: от 5 до 200

### 3. Ручное добавление сообщества

Если знаете конкретное сообщество:

1. Разверните блок "Добавить сообщество вручную"
2. Вставьте ссылку: `https://vk.com/community_name` или `club123456`
3. Нажмите "Добавить"

**Массовое добавление:**
- Разверните "Массовое добавление по списку ссылок"
- Вставьте несколько ссылок (по одной на строку)
- Нажмите "Добавить все"

### 4. Сбор контактов

Программа автоматически извлекает:
- 📱 **Телефон** - из блока контактов
- 📧 **Email** - из описания и контактов
- 🌐 **Сайт** - внешние ссылки сообщества
- 🏙️ **Город** - из информации о сообществе
- 👥 **Участники** - количество подписчиков
- ✅ **Верификация** - статус верифицированного сообщества

### 5. Экспорт в Excel

1. Нажмите кнопку "Скачать Excel" в панели статистики
2. Файл сохранится с именем `vk_communities_ГГГГ-ММ-ДД.xlsx`
3. В файле два листа:
   - **Сообщества** - полная таблица с данными
   - **Сводка** - статистика по найденным сообществам

## ⌨️ Горячие клавиши

- **F5** или **Ctrl+R** - Обновить страницу
- **F11** - Полноэкранный режим
- **F12** - Открыть/закрыть инструменты разработчика
- **Ctrl+Q** - Выход из приложения

```
├── build.bat             # Скрипт сборки для Windows
└── README.md             # Эта инструкция
```

### Как это работает

1. **Electron** упаковывает веб-приложение в десктопное
2. **Парсинг** работает через встроенный Chromium (нет CORS ограничений)
3. **Данные** сохраняются в памяти приложения
4. **Экспорт** создаёт Excel файл через SheetJS

### Преимущества десктопной версии

- ✅ **Нет CORS ограничений** - прямые запросы к VK
- ✅ **Работает оффлайн** - интерфейс не требует интернета
- ✅ **Быстрее** - нет задержек браузера
- ✅ **Удобнее** - ярлык на рабочем столе, полноэкранный режим
- ✅ **Надёжнее** - не зависит от CORS-прокси

## ⚠️ Важные замечания

### Ограничения VK

- **Капча**: VK может заблокировать частые запросы. Подождите 1-2 минуты
- **Частота запросов**: Между запросами пауза 1.5-2 секунды
- **Антиспам**: Не делайте слишком много запросов подряд

### Что делать если не работает

1. **Приложение не запускается**:
   - Проверьте, что установлен Node.js 18+
   - Запустите от имени администратора
   - Проверьте антивирус (может блокировать .exe)

2. **Ошибка при сборке**:
   - Удалите папку `node_modules` и `package-lock.json`
   - Запустите `npm install` заново
   - Проверьте интернет-соединение

3. **Белый экран в приложении**:
   - Нажмите F5 для обновления
   - Проверьте консоль (F12) на наличие ошибок
   - Пересоберите приложение

4. **Не находятся сообщества**:
   - Проверьте правильность написания ключевых слов
   - Попробуйте более общие запросы
   - Подождите, если VK заблокировал запросы

## 🛠️ Режим разработки

Для разработки и тестирования:

**1. Запустите веб-сервер в одном терминале:**

```bash
npm run dev
```

**2. Запустите Electron в другом терминале:**

```bash
npx electron electron/dev.js
```

Или создайте скрипт `dev.bat`:

```batch
@echo off
start cmd /k "npm run dev"
timeout /t 3
npx electron electron/dev.js
```
