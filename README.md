# VK Community Finder

Поиск сообществ ВКонтакте с автоматическим сбором контактов и экспортом в Excel.

## Возможности

- 🔍 Поиск сообществ по ключевым словам
- 📱 Автоматический сбор контактов (телефон, email, сайт, город)
- 👥 Подсчёт участников и проверка верификации
- 📊 Экспорт в Excel с форматированием
- 🔄 Два способа авторизации: через браузер или по логину/паролю

## Установка

1. Установите Python 3.10+ с https://www.python.org/downloads/
   - **ВАЖНО:** отметьте галочку "Add Python to PATH"

2. Запустите установку:
   ```
   install_python.bat
   ```

## Запуск

```
run_python.bat
```

## Использование

### Авторизация

**Рекомендуется:** оранжевая кнопка "Войти по логину/паролю"
- Введите телефон/email и пароль
- Если включена 2FA — введите код из приложения
- Работает через VK API напрямую

**Запасной вариант:** синяя кнопка "Войти ВКонтакте"
- Откроется браузер Chromium
- Войдите любым способом (QR-код, логин/пароль)
- Нажмите зелёную кнопку "✓ Я авторизовался"

### Поиск

1. Введите ключевые слова (например: "автосервис", "доставка еды")
2. Настройте параметры:
   - Максимальное количество результатов (10-500)
   - Собирать контакты или нет
3. Нажмите "Найти"

### Экспорт

Нажмите "Экспорт в Excel" и выберите папку для сохранения.

## Решение проблем

### Ошибка "window.init" или "auth_token_code"

Это означает, что запущена старая версия программы. Выполните:

```
clean_and_reinstall.bat
```

Этот скрипт:
- Удалит все кэши и старые файлы
- Переустановит все зависимости
- Переустановит браузеры Playwright

Затем запустите программу и используйте **оранжевую кнопку** "Войти по логину/паролю".

### Проверка кода

Чтобы проверить, правильный ли код авторизации:

```
check_auth.bat
```

Этот скрипт проверит:
- Наличие вызова `vk_api.VkApi(login=..., password=...)`
- Наличие вызова `vk_session.auth()`
- Привязку кнопки к функции `start_api_login`
- Отсутствие проблемных элементов (auth_token_code, QWebEngine, window.init)

**Правильная структура кода:**
```python
vk_session = vk_api.VkApi(login=self.login, password=self.password)
vk_session.auth()
```

### Другие проблемы

**Ошибка greenlet с Python 3.15:**
```
fix_dependencies.bat
```
Этот скрипт обновит все зависимости до совместимых версий.

**Программа не запускается:**
```
diagnose.bat
```
Этот скрипт проверит все компоненты и покажет, что именно не работает.

**Тест компонентов:**
```
python test_components.py
```
Проверит каждый модуль отдельно и покажет, какой из них не работает.

**Ошибка установки:**
```
python -m pip install --upgrade pip
pip install --upgrade -r requirements.txt
python -m playwright install chromium
```

**Капча от VK:**
- Подождите 5-10 минут
- Уменьшите количество результатов

**Двухфакторная авторизация:**
- Откройте приложение VK на телефоне
- Скопируйте код из раздела "Код подтверждения"
- Введите код в появившемся окне

## Технологии

- **PyQt6** — графический интерфейс
- **Playwright** — браузер для парсинга
- **vk_api** — прямая авторизация через VK API
- **openpyxl** — экспорт в Excel

## Требования

- Windows 10/11 (64-bit)
- Python 3.10+ (рекомендуется 3.13 или 3.14 для стабильности)
- ~500 МБ свободного места
- Интернет-соединение

**⚠️ Python 3.15:** Если у вас Python 3.15, запустите `fix_dependencies.bat` для установки совместимых версий зависимостей.
