# VK Community Finder - Поиск сообществ ВКонтакте

Десктопное приложение для Windows для поиска сообществ ВКонтакте через парсинг веб-страниц. Автоматически собирает контактную информацию и экспортирует данные в Excel.

## 🎯 Возможности

- 🔍 **Поиск сообществ** по ключевым словам
- 📱 **Сбор контактов** (телефон, email, сайт)
- 👥 **Информация о сообществе** (участники, город, описание)
- 📊 **Экспорт в Excel** с двумя листами (данные + сводка)
- 🚫 **Без дубликатов** - автоматическая фильтрация
- 📝 **Ручное добавление** по ссылке
- 📋 **Массовое добавление** по списку ссылок
- 🖥️ **Десктопное приложение** для Windows

## 🚀 Быстрый старт

### Скачать готовое приложение

Если у вас уже есть собранный `.exe` файл:

1. Запустите `VK Community Finder-1.0.0-Setup.exe`
2. Следуйте инструкциям установщика
3. Запустите программу с рабочего стола

### Собрать приложение самостоятельно

```bash
# 1. Установите зависимости
npm install

# 2. Соберите веб-приложение
npm run build

# 3. Создайте .exe файл
npx electron-builder --win --x64
```

Или просто запустите:

```bash
build.bat
```

Готовый установщик появится в папке `release\`

## 🎮 Использование

### Поиск сообществ

1. Введите ключевые слова (например: "автосервис", "доставка еды")
2. Нажмите "Найти"
3. Дождитесь сбора контактов
4. Экспортируйте в Excel

### Ручное добавление

1. Разверните "Добавить сообщество вручную"
2. Вставьте ссылку: `https://vk.com/community_name`
3. Нажмите "Добавить"

### Массовое добавление

1. Вставьте список ссылок (по одной на строку)
2. Нажмите "Добавить все"
3. Программа обработает их по очереди

## ⚠️ Важно

- VK может ограничивать частые запросы (капча)
- Между запросами пауза 1.5-2 секунды
- Программа работает через парсинг, а не через API
- Используйте ответственно и соблюдайте правила VK

## 🆘 Проблемы

Если возникли проблемы:

1. Проверьте **[README-WINDOWS.md](README-WINDOWS.md)** - раздел "Что делать если не работает"
2. Убедитесь, что Node.js версии 18+
3. Попробуйте пересобрать приложение
4. Проверьте консоль (F12) на ошибки
