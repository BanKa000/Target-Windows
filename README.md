# VK Community Finder

Программа для поиска сообществ ВКонтакте с экспортом в Excel. Написана на Go для максимальной стабильности и простоты.

## Возможности

- 🔍 Поиск сообществ по ключевым словам
- 👥 Подсчёт участников
- 📊 Экспорт в Excel с форматированием
- 🔐 Авторизация через токен доступа VK API

## Установка

### 1. Установите Go

Скачайте и установите Go с официального сайта:  
https://go.dev/dl/

**ВАЖНО:** При установке убедитесь, что Go добавлен в PATH

### 2. Соберите программу

Запустите:
```
install_go.bat
```

Этот скрипт:
- Проверит установку Go
- Синхронизирует зависимости (`go mod tidy`)
- Загрузит библиотеки (vksdk для VK API, excelize для Excel)
- Создаст файл `vk_finder.exe`

### 3. Запустите программу

```
run_go.bat
```

## Использование

### Шаг 1: Получите токен доступа

Токен доступа - это длинная строка, которая даёт программе доступ к вашему аккаунту VK.

**Как получить токен:**

1. Откройте в браузере эту ссылку:
   ```
   https://oauth.vk.com/authorize?client_id=2685278&scope=offline,groups&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&v=5.199
   ```

2. Авторизуйтесь в ВКонтакте (логин/пароль или QR-код)

3. После успешной авторизации вы попадёте на страницу с адресом вида:
   ```
   https://oauth.vk.com/blank.html#access_token=abc123def456...xyz789&expires_in=0&user_id=123456789
   ```

4. Скопируйте значение `access_token` - это длинная строка между `access_token=` и `&expires_in`

   **Пример:**
   ```
   URL: https://oauth.vk.com/blank.html#access_token=abc123def456ghi789jkl012mno345pqr678stu901vwx234yz&expires_in=0&user_id=123456789
   
   Токен: abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
   ```

5. Скопируйте эту строку (без `access_token=` и без `&expires_in`)

**💡 Совет:** Токен бессрочный (если указан `expires_in=0`), поэтому вводить его нужно только один раз.

### Шаг 2: Запустите программу и введите токен

1. Запустите `run_go.bat`
2. Программа покажет инструкцию и попросит ввести токен
3. Вставьте скопированный токен
4. Нажмите Enter

Программа проверит токен и начнёт работу.

### Шаг 3: Поиск сообществ

1. Выберите "1. Поиск сообществ"
2. Введите ключевые слова (например: "автосервис", "доставка еды")
3. Укажите максимальное количество результатов (10-500)
4. Нажмите Enter
5. Программа покажет найденные сообщества

### Шаг 4: Экспорт в Excel

1. После поиска выберите "2. Экспорт в Excel"
2. Выберите папку для сохранения
3. Файл будет сохранён с именем `vk_communities_ГГГГ-ММ-ДД.xlsx`
4. Файл будет содержать:
   - Название сообщества
   - Ссылка
   - Количество участников
   - Описание
   - Сайт, телефон, email, город (если доступны)

## Что такое токен доступа?

**Токен доступа** - это специальная строка, которая даёт программе право работать с вашим аккаунтом VK от вашего имени.

**Безопасность:**
- Токен даёт доступ только к тем функциям, которые вы разрешили (поиск сообществ)
- Токен не даёт доступа к вашим личным сообщениям
- Вы можете отозвать токен в любой момент в настройках VK
- Токен хранится только в памяти программы, не сохраняется на диск

**Срок действия:**
- Если в URL указано `expires_in=0` - токен бессрочный
- Если указан другой срок - токен действует указанное количество секунд

## Решение проблем

### Ошибка "Go не установлен"

1. Скачайте Go с https://go.dev/dl/
2. Установите с отметкой "Add to PATH"
3. Перезапустите командную строку
4. Проверьте: `go version`

### Не могу получить токен

**Проблема:** Ссылка не открывается или показывает ошибку

**Решение:**
- Убедитесь, что вы вошли в свой аккаунт VK
- Попробуйте другой браузер
- Очистите кэш браузера
- Попробуйте режим инкогнито

**Проблема:** После авторизации не вижу токен в URL

**Решение:**
- Убедитесь, что вы скопировали полную ссылку
- Токен находится между `access_token=` и `&expires_in`
- Пример: `access_token=ТОКЕН_ЗДЕСЬ&expires_in=0`

### Ошибка "Неверный токен"

**Проблема:** Программа говорит, что токен неверный

**Решение:**
- Убедитесь, что скопировали токен полностью (без пробелов)
- Убедитесь, что не скопировали `access_token=` или `&expires_in`
- Получите новый токен по инструкции выше
- Убедитесь, что токен начинается с `vk1.a.` (это правильный формат)
- Проверьте, что в URL было `expires_in=0` (бессрочный токен)

**Если программа показывает конкретную ошибку:**
- **Ошибка 5:** Токен недействителен - получите новый токен
- **Ошибка 9 (Flood control):** VK заблокировал запросы из-за частых попыток - подождите 15-30 минут
- **Ошибка 27:** Недостаточно прав - убедитесь, что в URL был параметр `scope=offline,groups`
- **Другие ошибки:** Скопируйте текст ошибки и покажите разработчику

Подробная инструкция: [FIX_FLOOD_CONTROL.md](FIX_FLOOD_CONTROL.md)

### Ошибка "Токен отозван" или "Токен истёк"

**Проблема:** Токен больше не работает

**Решение:**
- Получите новый токен по инструкции выше
- Введите новый токен в программу

### Ошибка при сборке программы

**Проблема:** `install_go.bat` выдаёт ошибку

**Решение:**
```bash
go mod tidy
go build -o vk_finder.exe vk_finder.go
```
