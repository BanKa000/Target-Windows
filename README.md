# VK Community Finder на Go

Программа для поиска сообществ ВКонтакте с экспортом в Excel. Написана на Go для максимальной стабильности и простоты установки.

## Преимущества Go версии

✅ **Один .exe файл** - нет проблем с зависимостями  
✅ **Нет проблем с версиями** - работает на любом Windows  
✅ **Прямые HTTP запросы** - без браузеров и JavaScript ошибок  
✅ **Быстрая установка** - скачал Go, собрал, запустил  
✅ **Нет ошибок greenlet** - Go не использует Python библиотеки  
✅ **Нет ошибок "window.init"** - прямая работа с VK API  
✅ **Direct Auth** - авторизация через официальное приложение VK (не требует client_secret)  
✅ **Автоматическая 2FA** - программа сама запрашивает код при необходимости

## Возможности

- 🔍 Поиск сообществ по ключевым словам
- 👥 Подсчёт участников
- 📊 Экспорт в Excel с форматированием
- 🔐 Авторизация через логин/пароль или токен

## Установка

### 1. Установите Go

Скачайте и установите Go с официального сайта:  
https://go.dev/dl/

**ВАЖНО:** При установке убедитесь, что Go добавлен в PATH

### 2. Соберите программу

Запустите:
```
install_go.bat
```

Этот скрипт:
- Проверит установку Go
- Синхронизирует зависимости (`go mod tidy`)
- Загрузит библиотеки (vksdk для VK API, excelize для Excel)
- Создаст файл `vk_finder.exe`

### 3. Запустите программу

```
run_go.bat
```

## Использование

### Авторизация

Программа предлагает два способа:

**1. Логин/пароль (рекомендуется)**
- Введите телефон/email и пароль
- Программа использует прямой HTTP-запрос к `https://oauth.vk.com/token`
- Используется официальное приложение VK для Android (app_id=2274003)
- Не требует client_secret или регистрации приложения в VK Dev
- Автоматически обрабатывает ошибки и 2FA

**2. Существующий токен**
- Если у вас уже есть токен VK API
- Вставьте его напрямую

### Поиск сообществ

1. Выберите пункт "1. Поиск сообществ"
2. Введите ключевые слова (например: "автосервис", "доставка")
3. Укажите максимальное количество результатов (10-500)
4. Программа покажет найденные сообщества

### Экспорт в Excel

1. После поиска выберите "2. Экспорт в Excel"
2. Программа создаст файл `vk_communities_ГГГГ-ММ-ДД.xlsx`
3. Файл будет содержать:
   - Название сообщества
   - Ссылка
   - Количество участников
   - Описание
   - Сайт, телефон, email, город (если доступны)

## Решение проблем

### Ошибка "Go не установлен"

1. Скачайте Go с https://go.dev/dl/
2. Установите с отметкой "Add to PATH"
3. Перезапустите командную строку
4. Проверьте: `go version`

### Ошибка авторизации

**Неверный логин/пароль:**
- Проверьте правильность ввода
- Если включена 2FA - программа автоматически запросит код из приложения VK

**Ошибка "invalid_client":**
- Эта ошибка больше не должна возникать
- Программа использует прямой HTTP-запрос к `https://oauth.vk.com/token`
- Используется официальное приложение VK для Android (app_id=2274003)
- Не требует client_secret или регистрации приложения в VK Dev
- Если ошибка всё же возникает, выполните `install_go.bat` для переустановки зависимостей
- Подробная инструкция: [FIX_INVALID_CLIENT.md](FIX_INVALID_CLIENT.md)

**Капча:**
- VK запрашивает капчу при частых запросах
- Подождите 5-10 минут
- Или используйте токен вместо логина/пароля

**Ошибка "need_captcha":**
- VK блокирует автоматические входы
- Получите токен вручную через https://oauth.vk.com/authorize
- Используйте вариант "2. Использовать существующий токен"

### Ошибка сборки

```
go mod tidy
go build -o vk_finder.exe vk_finder.go
```

### Программа не запускается

1. Убедитесь, что файл `vk_finder.exe` создан
2. Запустите из командной строки для просмотра ошибок
3. Проверьте антивирус (может блокировать .exe)

## Как это работает

1. **Авторизация**: Прямой HTTP-запрос к `https://oauth.vk.com/token`
   - Приложение VK для Android (app_id=2274003)
   - Не требует client_secret или регистрации приложения
   - Автоматическая обработка ошибок и 2FA
   - Функция `getVKToken()` выполняет POST-запрос с параметрами логина/пароля
2. **Поиск**: Прямой вызов API через `vk.Request("groups.search", params)`
3. **Парсинг**: JSON ответ парсится вручную через `json.Unmarshal`
4. **Экспорт**: Создание Excel файла через excelize

**Никаких браузеров!** Программа работает напрямую с VK API через HTTP-запросы и библиотеку vksdk.

## Получение токена вручную

Если автоматическая авторизация не работает:

1. Откройте в браузере:
```
https://oauth.vk.com/authorize?client_id=2274003&scope=offline&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token
```

2. Авторизуйтесь в VK

3. После авторизации вы будете перенаправлены на URL вида:
```
https://oauth.vk.com/blank.html#access_token=ВАШ_ТОКЕН_HERE&expires_in=0&user_id=ВАШ_ID
```

4. Скопируйте значение `access_token` из URL

5. В программе выберите "2. Использовать существующий токен"

6. Вставьте скопированный токен
