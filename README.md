# VK Community Finder - Поиск сообществ ВКонтакте

**Рабочая программа** для поиска сообществ ВКонтакте с автоматическим сбором контактной информации (телефон, email, сайт) и экспортом в Excel.

## 🎯 Возможности

✅ **Два способа авторизации**: через vk.com/login или VK ID SDK  
✅ **Поиск сообществ** по ключевым словам  
✅ **Автоматический сбор контактов**: телефон, email, сайт, город  
✅ **Гибкие настройки**: тип сообщества, количество результатов  
✅ **Экспорт в Excel** с форматированием  
✅ **Защита от дубликатов**  
✅ **Массовая обработка** с задержками (защита от блокировки)  
✅ **Работает на Windows** (Python + Playwright)

## 🚀 Быстрый старт

### 1. Установите Python

Скачайте и установите Python 3.10 или выше:  
👉 https://www.python.org/downloads/

**ВАЖНО:** При установке отметьте галочку **"Add Python to PATH"**

### 2. Установите программу

Откройте командную строку (cmd) в папке проекта и выполните:

```bash
install_python.bat
```

Этот скрипт:
- Установит все зависимости (PyQt6, Playwright, openpyxl)
- Скачает браузер Chromium для парсинга
- Займёт ~500 МБ места на диске

### 3. Запустите программу

```bash
run_python.bat
```

## 📖 Инструкция по использованию

### Шаг 1: Авторизация

Программа предлагает **два способа авторизации** — выберите любой:

#### Способ 1: Через vk.com/login (синяя кнопка)

1. Нажмите синюю кнопку **"Войти ВКонтакте"**
2. Откроется браузер с страницей входа VK
3. Авторизуйтесь любым удобным способом:
   - **Через QR-код** (сканируйте камерой телефона)
   - **По телефону/email и паролю**
   - Через другие методы входа
4. После успешного входа в браузере нажмите зелёную кнопку **"✓ Я авторизовался"** в программе
5. Программа проверит авторизацию и сохранит сессию

#### Способ 2: Через VK ID SDK (оранжевая кнопка)

1. Нажмите оранжевую кнопку **"Войти через VK ID"**
2. Откроется браузер с виджетом VK ID
3. Авторизуйтесь через виджет (автоматически определяет успех)
4. Программа сохранит сессию автоматически

**После авторизации:**
- Статус изменится на "Авторизован ✓"
- Сессия сохраняется — при следующем запуске авторизоваться не потребуется

**💡 Какой способ выбрать?**
- **vk.com/login** — проще, работает всегда, поддерживает QR-код
- **VK ID SDK** — официальный виджет, но требует настройки приложения в VK

### Шаг 2: Поиск сообществ

1. Введите ключевые слова (например: "автосервис", "доставка еды", "салон красоты")
2. Выберите тип сообщества:
   - **Все** - группы, паблики и встречи
   - **Группы** - только группы
   - **Публичные страницы** - только паблики
   - **Встречи** - только мероприятия
3. Укажите максимальное количество результатов (10-500)
4. Отметьте галочку **"Собирать контакты"** если нужны телефоны/email/сайты
5. Нажмите **"Найти"**

### Шаг 3: Просмотр результатов

Результаты отображаются в таблице:
- **Название** - имя сообщества
- **Ссылка** - URL на VK
- **Участники** - количество подписчиков
- **Телефон** - контактный телефон (если указан)
- **Email** - контактный email (если указан)
- **Сайт** - внешний сайт (если указан)
- **Город** - город сообщества (если указан)
- **Верифицировано** - статус верификации

### Шаг 4: Экспорт в Excel

1. Нажмите кнопку **"Экспорт в Excel"**
2. Выберите папку для сохранения
3. Файл сохранится с именем `vk_communities_ГГГГ-ММ-ДД.xlsx`
4. Откройте файл в Excel - все данные отформатированы

## ⚙️ Гибкие настройки поиска

### Тип сообщества

- **Все** - поиск по всем типам (группы + паблики + встречи)
- **Группы** - закрытые и открытые группы
- **Публичные страницы** - паблики, блоги, компании
- **Встречи** - мероприятия и события

### Количество результатов

Диапазон: **10 - 500** сообществ

**Рекомендации:**
- 10-50 - быстрый поиск для тестирования
- 50-100 - оптимально для большинства задач
- 100-500 - полный поиск (займёт больше времени)

### Сбор контактов

**Включено** (по умолчанию):
- Программа заходит на страницу каждого сообщества
- Извлекает телефон, email, сайт, город
- Занимает больше времени (1.5 сек задержки между запросами)

**Выключено**:
- Только базовая информация (название, ссылка, участники)
- Работает быстрее

## 🔧 Технические детали

### Как это работает

1. **Авторизация** (два варианта):
   - **Через vk.com/login**: Playwright открывает браузер со страницей входа VK
   - **Через VK ID SDK**: Playwright загружает HTML с виджетом VK ID, который автоматически обрабатывает авторизацию
2. **Сохранение сессии**: Cookies сохраняются в профиле браузера (`~/.vk_finder_profile`) для повторного использования
3. **Поиск**: Переходит на `https://vk.com/groups?q=запрос`
4. **Парсинг**: Извлекает ссылки на сообщества из HTML
5. **Детали**: Для каждого сообщества загружает страницу и ищет контакты
6. **Экспорт**: Сохраняет данные в Excel через openpyxl

### Почему Python, а не JavaScript?

**Проблемы JavaScript/Electron версии:**
- ❌ CORS блокирует запросы к VK
- ❌ Требуется авторизация через API (сложно)
- ❌ Нестабильные CORS-прокси
- ❌ Ошибки 404/503

**Преимущества Python версии:**
- ✅ Реальный браузер (Playwright) - нет CORS проблем
- ✅ Два способа авторизации: vk.com/login и VK ID SDK
- ✅ Сохранение сессии между запусками
- ✅ Стабильная работа
- ✅ Гибкие настройки

## ⚠️ Важные замечания

### Ограничения VK

- **Частота запросов**: Программа делает паузу 1.5 сек между запросами
- **Капча**: Если VK запросит капчу, программа остановится
- **Лимиты**: Не ищите больше 500 сообществ за раз

### Что делать если...

**Ошибка "Python не установлен"**
- Установите Python с сайта python.org
- При установке отметьте "Add Python to PATH"
- Перезапустите командную строку

**Ошибка при установке зависимостей**
```bash
# Попробуйте обновить pip
python -m pip install --upgrade pip

# Затем снова установите зависимости
pip install -r requirements.txt
```

**Ошибка установки браузеров Playwright**
```bash
# Установите браузеры вручную
playwright install chromium
```

**Программа не находит сообщества**
- Проверьте авторизацию (статус должен быть "Авторизован ✓")
- Попробуйте другие ключевые слова
- Уменьшите количество результатов

**VK запрашивает капчу**
- Подождите 5-10 минут
- Попробуйте снова
- Уменьшите количество результатов

**Контакты не собираются**
- Не все сообщества указывают контакты публично
- Проверьте что галочка "Собирать контакты" включена
- Некоторые контакты могут быть скрыты
