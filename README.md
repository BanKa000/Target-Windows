# VK Community Finder - Поиск сообществ ВКонтакте

Программа для поиска сообществ ВКонтакте через парсинг веб-страниц (без использования API). Автоматически собирает контактную информацию и экспортирует данные в Excel.

## 🚀 Быстрый старт

### Способ 1: Открыть готовый файл (рекомендуется)

1. Откройте папку `dist`
2. Найдите файл `index.html`
3. Откройте его двойным кликом в браузере (Chrome, Firefox, Edge)
4. Готово! Программа запустится

**Важно:** Файл полностью автономный — не требует интернета для работы интерфейса (но нужен интернет для запросов к VK).

### Способ 2: Запустить через локальный сервер

Если первый способ не работает:

```bash
# Установите зависимости (один раз)
npm install

# Запустите сервер разработки
npm run dev
```

Откройте в браузере: `http://localhost:3000`

### Способ 3: Собрать production-версию

```bash
# Установите зависимости
npm install

# Соберите проект
npm run build

# Откройте dist/index.html в браузере
```

## 📖 Инструкция по использованию

### 1. Поиск сообществ

1. В поле "Критерии поиска" введите ключевые слова (например: "автосервис", "доставка еды", "салон красоты")
2. Нажмите кнопку "Найти" или клавишу Enter
3. Программа найдёт сообщества и автоматически соберёт их контакты

**Расширенные настройки:**
- **Тип сообщества**: Группа / Публичная страница / Встреча
- **Сортировка**: По релевантности / По скорости роста
- **Макс. результатов**: от 5 до 200

### 2. Ручное добавление сообщества

Если знаете конкретное сообщество:

1. Разверните блок "Добавить сообщество вручную"
2. Вставьте ссылку: `https://vk.com/community_name` или `club123456`
3. Нажмите "Добавить"
4. Программа загрузит страницу и извлечёт контакты

**Массовое добавление:**
- Разверните "Массовое добавление по списку ссылок"
- Вставьте несколько ссылок (по одной на строку)
- Нажмите "Добавить все"
- Программа обработает их по очереди с паузой 2 секунды

### 3. Сбор контактов

Программа автоматически извлекает:
- 📱 **Телефон** - из блока контактов
- 📧 **Email** - из описания и контактов
- 🌐 **Сайт** - внешние ссылки сообщества
- 🏙️ **Город** - из информации о сообществе
- 👥 **Участники** - количество подписчиков
- ✅ **Верификация** - статус верифицированного сообщества

### 4. Управление результатами

- **Удалить сообщество**: нажмите красную кнопку корзины в строке сообщества
- **Открыть в VK**: нажмите синюю кнопку со стрелкой
- **Очистить всё**: нажмите кнопку "Очистить всё" в панели статистики

### 5. Экспорт в Excel

1. Нажмите кнопку "Скачать Excel" в панели статистики
2. Файл сохранится с именем `vk_communities_ГГГГ-ММ-ДД.xlsx`
3. В файле два листа:
   - **Сообщества** - полная таблица с данными
   - **Сводка** - статистика по найденным сообществам

**Колонки в Excel:**
- №, ID, Название, Ссылка, Тип, Описание
- Участники, Город, Сайт, Телефон, Email
- Статус, Активность, Верифицировано, Закрытое, Дата сбора

## ⚠️ Важные замечания

### Ограничения VK

- **Капча**: VK может заблокировать частые запросы. Если видите ошибку "VK запросил капчу" — подождите 1-2 минуты
- **CORS-прокси**: Программа использует публичные прокси для обхода ограничений браузера. Если прокси недоступен, программа автоматически переключится на другой
- **Частота запросов**: Между запросами к отдельным сообществам пауза 1.5-2 секунды для избежания блокировки

### Что делать если не работает

1. **Белый экран при открытии файла**:
   - Убедитесь что открываете `dist/index.html`, а не `index.html` из корня
   - Попробуйте другой браузер (Chrome/Firefox/Edge)
   - Запустите через локальный сервер: `npm run dev`

2. **Ошибка "CORS-прокси мог быть заблокирован VK"**:
   - Подождите 1-2 минуты
   - Попробуйте другой поисковый запрос
   - Проверьте интернет-соединение

3. **Не находятся сообщества**:
   - Проверьте правильность написания ключевых слов
   - Попробуйте более общие запросы
   - Измените тип сообщества в расширенных настройках

4. **Не собираются контакты**:
   - Не все сообщества указывают контакты публично
   - Программа собирает только общедоступную информацию
   - Попробуйте добавить сообщество вручную по ссылке

## 🔧 Технические детали

### Как это работает

1. **Парсинг поиска**: Программа загружает страницу поиска VK и извлекает ссылки на сообщества
2. **Сбор деталей**: Для каждого сообщества загружается отдельная страница
3. **Извлечение контактов**: Регулярные выражения ищут телефоны, email, сайты в HTML
4. **Дедупликация**: Сообщества идентифицируются по ID, дубликаты исключаются
5. **Экспорт**: Данные форматируются и сохраняются в Excel через библиотеку SheetJS

### Технологии

- **Frontend**: React + TypeScript + Tailwind CSS
- **Сборка**: Vite + vite-plugin-singlefile
- **Парсинг**: Регулярные выражения + CORS-прокси
- **Экспорт**: SheetJS (xlsx) + FileSaver.js

### Структура проекта

```

├── dist/

```
