# Быстрый старт

## Установка (один раз)

1. **Установите Go** с https://go.dev/dl/
   - При установке отметьте "Add to PATH"

2. **Соберите программу:**
   ```
   install_go.bat
   ```

## Запуск

```
run_go.bat
```

## Использование

1. **Авторизация:**
   - Выберите "1" для входа по логину/паролю
   - Введите телефон/email и пароль
   - Программа использует Direct Auth через официальное приложение VK
   - Если включена 2FA - программа автоматически запросит код из приложения VK

2. **Поиск:**
   - Выберите "1. Поиск сообществ"
   - Введите ключевые слова
   - Укажите количество результатов

3. **Экспорт:**
   - Выберите "2. Экспорт в Excel"
   - Файл сохранится в текущей папке

## Преимущества Go версии

✅ Один .exe файл - нет зависимостей  
✅ Нет ошибок greenlet, window.init  
✅ Прямые HTTP запросы к VK API  
✅ Direct Auth через официальное приложение VK (не требует client_secret)  
✅ Автоматическая поддержка 2FA  
✅ Быстрая и стабильная работа  

## Если что-то не работает

**Ошибка "Go не установлен":**
- Установите Go с https://go.dev/dl/
- Перезапустите командную строку

**Ошибка авторизации:**
- Проверьте логин/пароль
- Если включена 2FA - программа автоматически запросит код из приложения VK
- Или получите токен вручную (см. README.md)

**Ошибка "invalid_client":**
- Эта ошибка больше не должна возникать
- Программа использует Direct Auth через официальное приложение VK для Android
- Не требует client_secret или регистрации приложения в VK Dev

**Капча от VK:**
- Подождите 5-10 минут
- Или используйте токен вместо логина/пароля

Подробная инструкция: [README.md](README.md)
