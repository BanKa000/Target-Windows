# Быстрый старт

## Установка (один раз)

1. **Установите Go** с https://go.dev/dl/
   - При установке отметьте "Add to PATH"

2. **Соберите программу:**
   ```
   install_go.bat
   ```

## Запуск

```
run_go.bat
```

## Использование

1. **Авторизация:**
   - Выберите "1. Войти через браузер"
   - Откроется браузер с страницей авторизации VK
   - Войдите в аккаунт любым способом (логин/пароль, QR-код, и т.д.)
   - После успешной авторизации токен автоматически передаётся в программу
   - Работает с двухфакторной аутентификацией

2. **Поиск:**
   - Выберите "1. Поиск сообществ"
   - Введите ключевые слова
   - Укажите количество результатов

3. **Экспорт:**
   - Выберите "2. Экспорт в Excel"
   - Файл сохранится в текущей папке

## Преимущества Go версии

✅ Один .exe файл - нет зависимостей  
✅ Нет ошибок greenlet, window.init  
✅ OAuth авторизация через браузер (стандартный механизм VK)  
✅ Работает с двухфакторной аутентификацией  
✅ Не требует client_secret  
✅ Быстрая и стабильная работа  

## Если что-то не работает

**Ошибка "Go не установлен":**
- Установите Go с https://go.dev/dl/
- Перезапустите командную строку

**Ошибка авторизации:**
- Проверьте логин/пароль
- Если включена 2FA - программа автоматически запросит код из приложения VK
- Или получите токен вручную (см. README.md)

**Ошибка "invalid_client" или "incorrect app":**
- VK может блокировать некоторые app_id для OAuth
- Используйте опцию "2. Использовать существующий токен"
- Получите токен вручную через URL из раздела "Получение токена вручную" в README.md
- Попробуйте разные app_id (5157339, 3697615, 6121269)
- Подробная инструкция: [FIX_INVALID_CLIENT.md](FIX_INVALID_CLIENT.md)

**Браузер не открывается:**
- Скопируйте URL из консоли и откройте вручную
- Используйте опцию "2" для ввода токена вручную

**Капча от VK:**
- Подождите 5-10 минут
- Или используйте токен вместо логина/пароля

Подробная инструкция: [README.md](README.md)
