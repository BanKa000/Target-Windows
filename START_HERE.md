# Быстрый старт

## Что нужно

1. **Go 1.21+** - скачать с https://go.dev/dl/
   - ⚠️ При установке отметить "Add to PATH"

2. **Windows 10/11** (64-bit)

3. **Интернет** для работы с VK

## Установка (один раз)

```bash
install_go.bat
```

Это установит:
- Go библиотеки (vksdk для VK API, excelize для Excel)
- Создаст файл `vk_finder.exe`

## Запуск программы

```bash
run_go.bat
```

## Как пользоваться

### 1. Получите токен доступа

Токен - это длинная строка, которая даёт программе доступ к VK.

**Инструкция:**

1. Откройте в браузере эту ссылку:
   ```
   https://oauth.vk.com/authorize?client_id=2685278&scope=offline,groups&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&v=5.199
   ```

2. Авторизуйтесь в VK (логин/пароль или QR-код)

3. Вы попадёте на страницу с адресом вида:
   ```
   https://oauth.vk.com/blank.html#access_token=ТОКЕН_ЗДЕСЬ&expires_in=0&user_id=ВАШ_ID
   ```

4. Скопируйте значение `access_token` - это длинная строка между `access_token=` и `&expires_in`

   **Пример:**
   ```
   URL: ...#access_token=abc123def456...xyz789&expires_in=0...
   
   Токен: abc123def456...xyz789
   ```

5. Скопируйте эту строку (без `access_token=` и без `&expires_in`)

**💡 Токен бессрочный** (если `expires_in=0`), вводить нужно только один раз.

### 2. Запустите программу

```bash
run_go.bat
```

### 3. Введите токен

Программа попросит ввести токен. Вставьте скопированный токен и нажмите Enter.

### 4. Используйте программу

- **1. Поиск сообществ** - введите ключевые слова
- **2. Экспорт в Excel** - сохраните результаты в файл

## Если что-то не работает

**Go не найден:**
- Переустановите Go с отметкой "Add to PATH"
- Перезапустите командную строку

**Ошибка сборки:**
```bash
go mod tidy
go build -o vk_finder.exe vk_finder.go
```

**Не могу получить токен:**
- Убедитесь, что вы вошли в свой аккаунт VK
- Попробуйте другой браузер
- Очистите кэш браузера

**Неверный токен:**
- Убедитесь, что скопировали токен полностью (без пробелов)
- Убедитесь, что не скопировали `access_token=` или `&expires_in`
- Получите новый токен
- Токен должен начинаться с `vk1.a.` (правильный формат)
- В URL должно быть `expires_in=0` (бессрочный токен)

**Если программа показывает ошибку:**
- Программа теперь показывает конкретную ошибку VK API
- **Ошибка 9 (Flood control):** Подождите 15-30 минут и попробуйте снова
- Скопируйте текст ошибки и покажите разработчику

Подробная инструкция: [FIX_FLOOD_CONTROL.md](FIX_FLOOD_CONTROL.md)

**Токен отозван:**
- Получите новый токен по инструкции выше
