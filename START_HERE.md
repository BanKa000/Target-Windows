# Краткая инструкция по запуску

## Что нужно

1. **Python 3.10+** - скачать с https://www.python.org/downloads/
   - ⚠️ При установке отметить "Add Python to PATH"

2. **Windows 10/11** (64-bit)

3. **Интернет** для работы с VK

## Установка (один раз)

```bash
install_python.bat
```

Это установит:
- Python библиотеки (PyQt6, Playwright, openpyxl)
- Браузер Chromium для парсинга (~300 МБ)

## Запуск программы

```bash
run_python.bat
```

## Как пользоваться

1. **Авторизация** (два способа на выбор):
   - **Синяя кнопка "Войти ВКонтакте"** → войдите в аккаунт в браузере → нажмите "✓ Я авторизовался"
   - **Оранжевая кнопка "Войти по логину/паролю"** → введите данные → авторизация через VK API
2. **Поиск**: Введите запрос (например: "автосервис") → "Найти"
3. **Экспорт**: "Экспорт в Excel" → выберите папку

## Если что-то не работает

**Python не найден:**
- Переустановите Python с отметкой "Add Python to PATH"
- Перезапустите командную строку

**Ошибка установки:**
```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
playwright install chromium
```

**Программа не находит сообщества:**
- Проверьте авторизацию (статус "Авторизован ✓")
- Попробуйте другие ключевые слова

**Авторизация через QR-код не работает:**
- После сканирования QR-кода и подтверждения на телефоне
- Нажмите зелёную кнопку "✓ Я авторизовался" в программе
- Не ждите автоматического определения - VK делает редиректы

**Ошибка "Неверный логин или пароль":**
- Проверьте правильность ввода
- Если включена двухфакторная авторизация - программа запросит код
- Попробуйте авторизацию через браузер (синяя кнопка)

**Ошибка "Требуется двухфакторная авторизация":**
- Откройте приложение VK на телефоне
- Скопируйте код из раздела "Код подтверждения"
- Введите код в появившемся окне

**VK запрашивает капчу:**
- Подождите 5-10 минут
- Уменьшите количество результатов
